# Block A 实机验收记录

日期：2026-09-22

硬件：Tang Primer 20K + Dock、旋转臂霍尔 A/B 编码器、ADS1115、WDD35D4。

## 旋转臂

Tera Term 联合输出验证结果：

- CCW 过程中 `T` 持续增大，`TD` 为正；停止后 `TD=00000000`。
- CW 过程中 `T` 持续减小，`TD` 显示为 `FFFFFFxx` 形式的负补码；停止后
  `TD=00000000`。
- `T` 穿过零点后进入负数补码表示，计数连续。

结论：CCW 定义为正，CW 定义为负；`theta` 和 `theta_dot` 的方向、静止与运动关系通过。

## 摆杆

- 竖直位置按实测 ADC 三点标定定义为 `alpha=0`。
- 拨动摆杆时 `A` 明显变化，`AD` 在运动期间非零。
- 摆杆停止后 `AD` 回到 0 附近，仅保留小范围采样波动。
- 正负 π 边界通过回绕修正，没有产生错误的大角速度跳变。

## 联合验证

保持旋转臂基本不动、只拨动摆杆时：`TD` 保持为 0，`A/AD` 按运动变化；机械操作造成的
少量 `T` 变化属于底座被轻微带动。四个状态量已能同时通过 115200 UART 输出。

结论：Block A 的 `theta / theta_dot / alpha / alpha_dot` 实物验证完成。本检查点之后的工作
进入 LQR 输出离线验证，在接入 IBT-2 和电机前先确认控制方向及数值范围。
