# ADS1115 电气测量记录

日期：2026-09-18。

| 测量项 | 结果 |
|---|---:|
| 模块输入电压 | 5.00 V |
| 工作电流 | 约 3 mA |
| SDA 空闲电压 | 3.296 V |
| SCL 空闲电压 | 3.296 V |
| 断电 SDA 到模块 `+5V` 输入 | 73.64 kΩ |
| 断电 SCL 到模块 `+5V` 输入 | 73.64 kΩ |

结论：SDA/SCL 的实测高电平对 FPGA 3.3 V IO 安全。两个 73.64 kΩ 结果测到的是
总线到模块 5 V 输入之间的内部等效路径，不能直接解释为上拉电阻。下一项验收是接入
J14/J16 后确认 ADS1115 地址 0x48 应答，正常采样后 `sensor_valid=1`。
