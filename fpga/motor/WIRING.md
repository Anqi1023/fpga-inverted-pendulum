# IBT-2 四路接口与接线计划

2026-09-17 更新。以下 FPGA 分配来自用户本轮确认；尚未进行实物接线或电机测试。
采用 IBT-2 的 RPWM/LPWM/R_EN/L_EN，不存在外接 DIR 端子。用户本轮将功率芯片型号确认为 BTS7960B ×2，缓冲为 74HC244D；此记录替代此前 BTN7960B 识别记录。仓库早期硬件汇总属于历史记录，应以本更新为准。

## GPIO 与电平转换（型号与方向更正）

实物丝印 LJ245A 对应 SN74LVC4245A，用户提供的商家接线截图与此型号一致。此前 SN74LVC8T245 识别及 A侧接FPGA 的暂拟方案作废。当前使用现有 CJMCU-245；HCT/AHCT仅是此前备选，不是当前接线器件。

| FPGA信号 | FPGA球位 / Dock接口 | 转换器3.3V输入 | 转换器5V输出 | IBT-2输入 |
|---|---|---|---|---|
| rpwm | T6 / PMOD0 | B1 | A1 | RPWM |
| lpwm | P6 / PMOD0 | B2 | A2 | LPWM |
| r_en | T7 / PMOD0 | B3 | A3 | R_EN |
| l_en | R8 / PMOD0 | B4 | A4 | L_EN |

球位不是PMOD物理针序；按板卡标识对应，不按照片左右猜针序。FPGA约束保持LVCMOS33、4mA、内部下拉，外部下拉不能由内部下拉替代。

| 模块端子 | 当前手动测试设计 |
|---|---|
| VCA | 稳压5V，与IBT-2逻辑VCC同一逻辑电源域 |
| VCB | 3.3V，与FPGA的3.3V逻辑域对应 |
| GND | FPGA、转换器、逻辑电源、IBT-2共地 |
| DIR | 直接接GND，固定B→A；不是电机方向信号 |
| OE（低有效） | 经10kΩ上拉到VCA；常开使能开关接在OE与GND之间 |
| B1–B4 | 每路各用一只10kΩ电阻下拉到GND |
| IBT-2 RPWM、LPWM、R_EN、L_EN | 每路各用一只10kΩ下拉到GND，靠近驱动板端子安装 |
| B5–B8 | 固定B→A时，未使用输入接GND |
| A5–A8 | 未使用输出不接，不短接地 |

共9只外加10kΩ电阻：1只OE上拉、4只转换器输入下拉、4只驱动输入下拉。电阻从信号节点分支接电源或地，不串在信号路径中，四路信号不互相短接。

```text
VCA(5V) ── 10kΩ ──┬── OE
                  │
              常开使能开关
                  │
                 GND

每路信号 ──────────┬── 接收端
                  │
                 10kΩ
                  │
                 GND
```

开关断开：OE高，输出高阻；驱动端下拉保持四路输入为低。开关闭合：OE低，允许B→A转换。上电前开关必须断开；保持闭合重新上电不会自动恢复“禁止”，因此这只是手动测试使能，不是自动上电联锁或急停。10kΩ为本次选定设计值，不代表已经测量验证；模块已有偏置电阻和接线异常仍需在无电机测试中检查。

OE节点可能达到5V，不直接连接FPGA GPIO。后续自动控制OE需单独设计隔离5V的控制级及默认关断逻辑。5V不得接VCB或FPGA GPIO；PMOD 3V3不得替代IBT-2的5V逻辑供电。逻辑5V/3.3V来源、模块去耦及最终供电布线仍需核对，不将电机12V接入逻辑电源端。

## 四路真值表

| 控制状态 | RPWM | LPWM | R_EN | L_EN |
|---|---|---|---|---|
| 上电初始化/复位/未解锁/STOP/等待/失去许可 | 0 | 0 | 0 | 0 |
| 已使能逻辑正向 | PWM | 0 | 1 | 1 |
| 已使能逻辑反向 | 0 | PWM | 1 | 1 |
| 接口层检测到方向变化的空白周期 | 0 | 0 | 0 | 0 |

占空比 0% 而命令仍为运行时，两 PWM 为 0、两 EN 仍为 1；因此它不是 STOP，不应作为释放驱动的办法。BTS7960 的 INH=0 禁止桥驱动；INH=1、IN=0 为低侧导通。此处 STOP 采用禁用，不承诺机械立即停稳。

方向只表示 RPWM 分支或 LPWM 分支。实际电机运动方向待低占空比实测，不标为机械左/右。

## 安全边界

- RTL 复位/撤销许可使四路输出为零。配置完成后的初始化是零，但 FPGA 未配置、重新下载、掉电时不能只依靠 RTL 保证输出。
- OE与下拉按上表实施；关闭为高阻而非主动输出零。设计已确定但尚未实测：需检查断开使能时的驱动端电平、供电顺序、断电回灌及下载期间状态，不据RTL仿真推断硬件保护已通过。
- 四路均需默认确定状态，不能让转换器输入悬空。最终 /OE 与急停方案不得依赖未初始化 FPGA 信号。
- 状态机换向先禁止，默认等待 1 秒并要求 STOP 状态重新解锁；接口层另在方向变化时至少保留一个完整时钟的空白周期。后者是数字互锁，不代表已经计算了功率器件死区或电机停稳时间。
- 控制输入目前必须同步。复位、按键/拨码、许可/急停输入管脚、同步释放和防抖方案尚未完成，不直接连接原始按键。
- R_IS/L_IS 不使用、不接 FPGA，未创建任何对应端口或约束。
- B+/B− 接电机电源、M+/M− 接电机。具体动力线识别、保护和接线仍待实物；今天不连接功率侧。

## 必须等实物确认

电机动力线、联轴器能否脱开、机械行程、实际转向、停稳时间、启动占空比、电流、发热、异响以及失电/下载时的实际驱动状态。电源保护和急停需先确认再安排实测。
