# 第一步：普通按键输入同步与消抖

目的：把一次真实按下转换为一个时钟周期的事件，供后续启动和方向控制使用。

- `rtl/button_input.v`：两级同步、连续稳定判定、单周期按下事件。
- 默认270000拍，对应27MHz时钟下10ms稳定窗口，另有同步延迟。
- `ACTIVE_LEVEL`参数支持高/低有效；默认0不是实物按键极性的确认。
- `pressed`反映过滤后的按住状态；`press_pulse`用于一次性操作。
- 上电或复位时按住：状态可以变为按住，但不产生事件；必须先稳定释放再按下。
- 这是普通命令按键模块，不用于急停的快速关断路径。停止优先级、急停锁存、复位同步释放和按键管脚在后续板级集成中处理。

在本目录运行：

```powershell
vsim -c -l button_simulation.log -do run_buttons.do
```

成功标准：出现`HENGXIN_BUTTON_INPUT_PASS`，错误数为0。
测试覆盖两种有效电平、最小窗口及4拍窗口、按下/释放抖动、长按、重复按下、上电按住、运行中复位并保持按住。
仿真缩短稳定窗口以加快运行；不能模拟真实亚稳态概率，也不能代替后续布局布线及板级检查。

本步骤独立仿真，尚未接入原电机顶层或增加GPIO约束；原电机工程保持不变。不生成电机下载位流。
出错时提供运行命令、当前目录与日志最后30行。
