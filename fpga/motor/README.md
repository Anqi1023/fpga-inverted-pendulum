## 频率和占空比

20 kHz 是本次离线设计的可修改候选值，不是已通过电机实测的参数。CLK_HZ 必须大于零，PWM_HZ 必须大于零且整除 CLK_HZ，计数周期至少 2。

27,000,000 / 20,000 = 1350 个时钟周期，PWM 周期 50 μs。

| 占空比 | 高电平时钟数 | 高电平时间 |
|---|---|---|
| 10% | 135 | 5 μs |
| 20% | 270 | 10 μs |
| 30% | 405 | 15 μs |

其他占空比按整数除法向下取整。顶层参数 DUTY_PERCENT 默认 10；控制模块允许动态输入，但大于 30 会关断并取消解锁。此上限不构成电流限制。PWM 启动先等待一个完整周期再加载占空比，避免恢复旧脉宽。

## 控制协议

所有输入必须与 clk 同步；当前顶层不是可直接连接开关的板级顶层。

1. command=00 或 11 表示 STOP，01 正转，10 反转。
2. permit=1、占空比合法且等待结束后，在 STOP 状态给 arm 一个新的 0→1 脉冲，进入 READY。
3. 再给正转或反转命令才运行。上电已保持 arm=1 或已有运行命令不会自动启动。
4. 运行中 STOP、反向命令、撤销 permit、超限占空比会关断。复位同样关断，且保持 DIR。
5. 关断后等待 STOP_CYCLES（默认 27,000,000 拍，即 1 秒），回到未解锁状态；必须重新回到 STOP 并提供新的 arm 脉冲。
6. 等待过程中出现的 arm 脉冲不生效。DIR 仅在重新启动时改变。

1 秒只是离线控制等待值，不保证电机已经静止，机械实测前须复核。STOP 定义为撤销逻辑驱动请求，不承诺瞬时制动。默认 0% 时 PWM 为零，运行状态仍可能保持逻辑 EN，必须通过 STOP/permit 撤销请求。

配置时寄存器初始化用于高云综合；它不能保证 FPGA 配置之前、下载期间或失去供电时外部驱动的状态。后续必须确认硬件下拉、驱动使能和急停电路。

## 复现

在本目录 PowerShell 执行：

```powershell
.\run_sim.ps1
gw_sh build_synth.tcl
```

如果 PowerShell 提示禁止运行 `.ps1`，无需改变系统设置。在本目录直接执行：

```powershell
vsim -c -l simulation.log -do run_modelsim.do
```

如果已经进入 `ModelSim>` 提示符，先用 `cd` 切换到本工程的 `fpga/motor` 目录，再执行 `do run_modelsim.do`。直接调用 ModelSim 时也必须核对末尾 PASS 标记和错误数。

仿真必须出现 HENGXIN_MOTOR_OFFLINE_PASS；脚本同时检查退出码与标记，不能只看退出码。仿真采用真实 PWM 分频比例，但把等待时间缩短为 20 拍；不证明真实电机在 1 秒内停止。

build_synth.tcl 只执行综合。可以在云源打开 motor_offline.gprj 查看代码，但不要运行 Run All / Place & Route / Programmer。约束未完成，当前没有上板位流。

## 本轮验证范围

- 初始复位后保持启动命令与 arm，不自动启动。
- STOP → FORWARD → STOP → REVERSE → STOP。
- 两方向 10%、20%、30% 的高电平拍数和 1350 拍周期；0% 无脉冲。
- 直接反向、等待中解锁、占空比 31%、permit 撤销、11 命令、运行中复位。
- DIR 改变之前已有禁用间隔；PWM 不越过逻辑 EN；两路 PWM 不同时有效；默认接口锁定。
- 未覆盖实物电流、转速、机械停稳、按键抖动和电平兼容性。

电机资料暂按用户提供规格：12 V 永磁有刷、额定 360 mA、堵转 2.8 A、1:20 减速。没有使用未知的动力线线序。
