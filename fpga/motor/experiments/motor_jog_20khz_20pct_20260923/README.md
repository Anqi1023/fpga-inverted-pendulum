# Tang Primer 20K 短时点动测试（2026-09-23）

此独立工程提供可综合的实板 Verilog，不是仿真激励。目标器件 GW2A-LV18PG256C8/I7，27 MHz，PWM 20 kHz、固定 20%（270/1350 时钟）；每次使能最多 200 ms，结束后锁定 1 s。PWM 首个完整周期用于装载占空比；超时立即撤销使能，不等待 PWM 周期结束。

## 操作

- S0：复位并撤销输出；松开后不自动启动。
- S1：按一次点动一次；长按不会连续点动，上电时按住也不会启动。锁定期间的按键不排队，须松开重按。
- S2：停止优先，经过两级同步后关闭输出，不经过 10 ms 消抖。它不是独立硬件急停。
- S3：待机时切换方向；运行时按下只中止运行，不立即反转，锁定期间忽略。
- LED4：使能期间亮约 200 ms；LED2：可接受启动时亮（锁定期间灭）；LED5：反向选择。

连接与原测试工程相同：T6→B1→A1→RPWM；P6→B2→A2→LPWM；T7→B3→A3→R_EN；R8→B4→A4→L_EN。电平板 VCA=5 V、VCB=3.3 V、DIR=GND，OE 按现有使能连接。按板卡约束与实际丝印对应，不能靠照片中左右位置推测孔位。

## 文件与构建

- 顶层：`dock_motor_jog.v`；项目：`dock_motor_jog.gprj`。
- Gowin IDE V1.9.12.03：在本目录执行 `gw_sh build.tcl`。
- 下载文件：`impl/pnr/dock_motor_jog.fs`，Gowin Programmer 使用 SRAM Program；这与旧的 `dock_motor_test.fs` 是不同文件。
- ModelSim：在本目录执行 `vsim -c -l simulation.log -do run.do`，检查 `JOG_TEST_PASS`。
- 所需三个公共模块复制在本目录，形成独立快照，不修改旧程序。

## 验证记录

2026-09-23 ModelSim 通过：启动时长按不动作、运行超时、20% PWM 周期计数、长按不重启、停止优先、反向输出互斥、运行中方向键中止、1 s 锁定行为和复位不重启。仿真为缩短执行时间使用 100 时钟点动/50 时钟锁定；实板参数为 5,400,000/27,000,000 时钟。

Gowin 综合及布局布线成功，生成 FS；27 MHz 约束下 Setup/Hold 违例端点均为 0，报告 Fmax 170.642 MHz。PNR 引脚报告核对 T6/P6/T7/R8 与原配置一致。这不等于实物已验收。

## 首轮检查与限制

先关闭台式电源 CH1（电机电源），保留逻辑电源，下载新 FS。按 S1 应看到 LED4 短亮、自动熄灭，锁定结束 LED2 亮；用示波器确认约 50 µs 周期、10 µs 高电平，脉冲包不超过 200 ms。验证停止、方向和复位后再评估带电机测试。

截至生成本程序时，用户明确 B+/B−/M+/M− 仍是细杜邦线；没有把它视为已排除的故障。首次带电机前需换为适合电流及端子的功率线，完成可靠夹紧，并具备独立电源切断手段。0.100 A 是此前待机排查的限流值，不是电机额定电流；代码不授权提高电流或在不合适接线上试转。

现有证据为输入 PWM 约 20 kHz/10%，供电及使能已复核，但电机端有效输出尚未确证。提高到 20% 不能保证解决不转，且不替代驱动输出诊断。程序没有电流/位置反馈、机械限位或独立故障关断，不是闭环倒立摆或最终安全控制器。
