# 板级保护信号测试

本文件只用于 CH1 电机动力输出关闭时的控制信号测试。USB 和原有逻辑 5 V 保持供电，接线不变。
输出固定正向、1 kHz、10%，每次信号启动最多 5 秒，然后停止并等待 1 秒。

## 本版本的按键和 LED

| 标记 | 本版本作用 |
|---|---|
| S0 | 复位，回到锁定 |
| S1 | 锁定时：手动清除；LED2 就绪后再次按：启动控制信号。两次独立按下 |
| S2 | 注入逻辑急停请求，锁定输出 |
| S3 | 注入故障请求，锁定输出；不再用于换向 |
| LED2 | 清除后等待结束，可以启动 |
| LED4 | 两路使能正在输出 |
| LED5 | 锁定；不再表示反向 |

S2/S3 只经过两级同步，不经过普通启动键的 10 ms 防抖。按键释放不会自动解除锁定。
S2 是对 protection.v 急停输入的板上验证，仍不是独立硬件断电急停；S3 是人为故障注入，并非传感器故障检测。

## 分步测试

1. CH1 输出保持关闭。下载后等待 2 秒，不按键：应仅 LED5 亮，LED2/LED4 灭，RPWM/LPWM/R_EN/L_EN 对逻辑 GND 均接近 0 V。
2. 点按并松开 S1，等约 2 秒：LED5 灭、LED2 亮、LED4 灭，电机控制输出仍为 0。
3. 再按一次 S1：LED4 亮、LED2 灭、LED5 灭，R_EN/L_EN 约 5 V（IBT-2 端）。5 秒后自动停止，约 1 秒后 LED2 重新亮；持续按住 S1 不重复启动。
4. 再次启动，在 LED4 亮时按住 S2：LED4 熄灭、LED5 亮、LED2 灭；四路 IBT-2 输入应接近 0 V。松开 S2 后保持锁定，不能自己恢复输出。
5. 先松开 S2/S3。按 S1 只清除锁定，等 LED2 亮，另一次 S1 才能启动。按住 S2 时按 S1 不能清除；一直按住 S1 再松 S2 也不能自动清除或重启。
6. 对 S3 重复故障注入、松开后锁定和手动恢复试验。
7. 运行中按 S0，输出停止；松开后回到 LED5 锁定，须重新清除并启动。

先确认每一步 LED 和静态电平，再讨论带电机的短时测试。万用表只能确认持续关断，不能证明瞬态关断延迟；测量延迟需要示波器/逻辑分析仪。
