# 5% 启动死区初步测试

基于 1 kHz/30% 点动版本，仅把顶层 DUTY_PERCENT 改为 5。引脚和控制方式保持一致。
27 MHz 时钟，PWM 1 kHz，每周期 27000 时钟；高电平 1350 时钟（50 µs）。
S1 一次运行 200 ms 后自动撤销两路 PWM 和使能，之后等待 1 秒；S2 提前停止；就绪时 S3 切向。
LED4 表示输出正在运行；LED2 表示就绪；LED5 亮表示反向。新下载默认正向。

## 测试方法

1. 关闭 CH1，USB 和逻辑电源保持供电，下载本文件，使用 SRAM Program，等 Finished。
2. CH1 关闭时先按一次 S1，确认 LED4 短亮后自动熄灭；待 LED2 重新亮。
3. 电源保持 12 V、限流 0.5 A，旋转臂活动范围留空，线缆留出余量。开启 CH1。
4. 默认正向，按一次 S1。每次等完全停稳且 LED2 亮后再按，总共试 3 次。不要用手助推。
5. 关闭 CH1。记录明显转动的次数（0/3～3/3）、是否仅抖动、供电是否进入 CC。

若 5% 稳定启动，再向更低占空比缩小范围；若不能稳定启动，在 5% 到 10% 之间继续测。
这只是 200 ms 测试窗口下的启动表现，需要正反向分别记录，不能推断任意负载下的通用死区。
没有自动停止时按 S2 并关闭 CH1；S2 是功能停止，不是独立硬件急停。

5% 实板结果（2026-09-26）：用户反馈“3次都完全不动”，启动成功 0/3。按前一步默认正向、200 ms 试验记录；实际电流与 CV/CC 状态尚未报告。下一步测试 7%。
