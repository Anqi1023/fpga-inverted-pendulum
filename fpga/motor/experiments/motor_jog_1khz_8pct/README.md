## 实物测试

1. 关闭 CH1 输出，USB 与逻辑电源保持供电；选择上述文件，SRAM Program，等 Finished。
2. CH1 关闭时按一次 S1，确认 LED4 短亮后自动熄灭，等待 LED2 就绪。
3. CH1 设定保持 12 V、限流 0.5 A；活动范围留空后开启输出。
4. 默认正向（LED5 灭），按 S1 试三次，每次从完全静止且 LED2 就绪开始，不用手助推。
5. 关闭 CH1，记录明显转动次数、是否仅抖动或完全不动；若出现 CC，同时记录，不提高限流。

若未自动停止，按 S2 并关闭 CH1。S2 是功能停止，不是独立硬件急停。
已报告：5% 三次完全不动；7% 一次明显转动、两次只抖动。8% 实板结果（2026-09-26）：用户反馈“都明显转动”，按前一步默认正向三次试验记录为明显启动 3/3；实际电流与 CV/CC 未报告。8% 是已测试点中正向三次均成功的最低占空比，不能据此断言精确死区或任意条件下均可启动。
反向实板结果（2026-09-26）：用户反馈“都有明显转动”，按上述反向三次试验记录为明显启动 3/3。之后 7% 反向反馈三次都不动。8% 正反向各三次均成功，本轮启动死区初步记录已完成；完整数据见 motor-test-record-2026-09-26.md。
结果仅适用于本次供电、机构负载、方向与 200 ms 窗口，不保证任意转角、负载或后续闭环中都可启动。
