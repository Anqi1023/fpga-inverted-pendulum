# 1 kHz、30% 占空比、200 ms 自动停止的点动测试

由独立的 1 kHz/20% 点动工程复制。唯一 RTL 功能变更为顶层 `DUTY_PERCENT=20` 改成 `30`。
20% 工程及其下载文件保留，不操作当前 FPGA，也不改变任何硬件接线。

## 参数和按键

- 时钟 27 MHz，PWM 1 kHz：周期 27000 时钟（1 ms），每个完整脉冲高电平 8100 时钟（300 µs）。
- S1：一次运行 5400000 时钟（200 ms），随后自动撤销 PWM 和两路使能。按住不重复运行。
- 停止后等待 1 秒再接受启动；LED2 亮表示就绪。
- S2：提前停止，为同步后的功能停止，不是独立硬件急停。
- S3：停稳并且 LED2 亮时切换方向；运行中按下会结束本次点动，不会立即反转。
- LED4：约 0.2 秒运行期间亮，撤销驱动后灭；机械运动可能有惯性滑行。
- LED5：反向指示，下载或复位后默认正向。

## 文件与使用

Programmer 下载文件：

```text
D:\FPGA\hengxin\motor-jog-1khz-30pct\impl\pnr\motor_jog_1khz_30pct.fs
```

本目录也保留相同文件的副本。

1. 先完成并记录 20% 测试，再切换 30% 文件。
2. 关闭电机电源 CH1 输出，USB 和逻辑电源保持供电。
3. Gowin Programmer 的 FS File 选择上面的文件，保持 SRAM Program，并重新执行下载，等 Finished。
4. CH1 仍关闭：等 LED2 亮，按一次 S1，确认 LED4 约 0.2 秒后自动熄灭，约 1 秒后 LED2 再亮。
5. 电机供电保持 12 V、限流 0.5 A；旋转臂活动范围留空，线缆留有余量。开启 CH1，按一次 S1 进行短时试转，随后关闭 CH1。
6. 若出现 CC 或电压下降，记录该现象，不自行提高限流。若没有自动停止，按 S2 并关闭 CH1。

这个文件用于 30% 短时试转；不能凭主观转动快慢宣称速度与占空比线性，也不能把电源屏幕显示当作启动峰值电流。
S1 的 LED4 计时比机械停转时间更能反映自动撤销驱动是否执行。
