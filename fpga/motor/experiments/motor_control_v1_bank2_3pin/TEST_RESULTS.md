## ModelSim

以下三项通过，最终日志均 0 错误、0 警告：

1. 正式三引脚链与原四引脚链对比：复位锁定、人工清除、正反转、零和低于 1% 命令、
   运行中禁用与重新使能不重放、fault/estop/permit_in 停机锁定、看门狗失联、迟到命令、
   越界命令与复位。在两种时钟沿后比较波形和状态，PWM 必须被使能门控且正反互斥。
   此测试缩短 PWM、STOP、watchdog 周期以检查连接和保护行为，不是新的实时间 100 ms 测试。
2. 板级按键：上电长按不启动、清锁不启动、长按只点动一次、S2/S3 和同时故障锁定、
   清除后重新启动、复位等。等待及按键消抖参数在仿真中缩短。
3. 实际 27 MHz 下的 200 ms 点动：共用使能 5400000 拍、1 kHz / 10%、
   199 个完整 PWM 脉冲、总高电平 537300 拍；控制更新间隔 540000 拍即 20 ms。

未重跑未修改协议核心的全部旧回归；既有真实 100 ms watchdog 和整数截断验证保留在
motor_control_v1_100ms / control_u_adapter_v1 历史包中，未冒充本次新测试。

## 硬件与联调边界

- 使用本方案需摄像头及占用 T11/P11/T12 的其他外设不连接，C 联合工程也不能重用三脚。
- 同一 T12 输出分接转换器 B3、B4 输入；两个转换器输出 A3/A4 分别到 R_EN/L_EN，不能短接。
- 本位流是 B 独立点动程序，非 ABC 联合 TEST_U=0 程序。
- 新版尚未上板；仿真不是实物测试。先 CH1 关闭验证零输出，再按 README 进行短时点动。
- C 正式模块只做核心综合与连接回归，联合工程的引脚、时序和运行行为仍需 C 在联合工程验证。
- 本记录随新版工程提交 GitHub；未自动下载，硬件状态仍为未验证。
