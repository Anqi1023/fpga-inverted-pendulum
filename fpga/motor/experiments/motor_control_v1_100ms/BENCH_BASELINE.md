# 本次修改前的用户实测基线

记录来源：本任务用户反馈。对象为旧 motor_control_v1_20ms（60 ms 超时、0.1% 精度）独立模拟 C 点动版本。

旧位流 SHA-256：10CB7EF2D8AE0A0E46CE7BDB6CC5B1D9668C4FAE9E0568B07F9C24FD05F93097。

- S1 点动：用户反馈“明显转动”；随后恢复运行步骤确认转动后自动停止。
- 停止/就绪后 S2：锁定指示符合预期；一次 S1 清锁保持不动，再次 S1 可点动并停下。
- 停止/就绪后 S3：锁定保持符合预期；一次 S1 清锁不启动，再次 S1 点动并停下。
- 按住 S1 约 3 秒：只发生一次点动，继续按住不重复。

上述为用户观察，不是仪器测出的精确 200 ms 时长；未据此证明运行中急停延迟、60 ms 硬件超时或真实 C 联合控制。本补充版改成 100 ms 和整数截断后，不能直接继承为“新版所有功能已上板通过”。
