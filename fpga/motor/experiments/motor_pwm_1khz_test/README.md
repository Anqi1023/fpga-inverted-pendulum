# IBT-2 空载输出对照测试：1 kHz、10%

基于 `D:\FPGA\hengxin\motor-dev\fpga\motor\board\dock_motor_test.gprj` 的独立副本。
用途：保持电机与 IBT-2 的 M+、M− 断开，比较 20 kHz 和 1 kHz 时驱动板的输出。

## 唯一功能变更

`rtl/dock_motor_test.v` 中，`motor_buttons_top` 实例明确指定：

```verilog
.PWM_HZ(1000), .DUTY_PERCENT(10)
```

27 MHz 时钟下，周期 27000 个时钟（1 ms），高电平 2700 个时钟（100 µs）。
原来的 20 kHz 版本高电平为 5 µs。原工程和原 `.fs` 文件未修改。

引脚约束和底层模块保持原样；底层模块的默认 `PWM_HZ=20000` 被上述实例参数覆盖，不必逐个修改。

## 下载和首次检查

已生成的下载文件：`D:\FPGA\hengxin\motor-pwm-1khz-test\board\impl\pnr\dock_motor_1khz.fs`。
本目录下也保存了同内容的 `dock_motor_1khz.fs`。

1. 台式电源 CH1 输出关闭；电机线保持与 M+、M− 断开。USB 和既有逻辑电源保持供电。
2. 在 Gowin Programmer 原设备行中，用本版本 `.fs` 替换原文件，沿用 SRAM Program 下载方式。
3. 下载成功后等 LED2 亮，再按 S1，LED4 应亮。
4. 先保持 CH1 关闭，用万用表 Freq 挡测 IBT-2 RPWM 对 GND，应约 1 kHz。
5. 按 S2 停止，等待下一步的驱动输出对比。确认频率后才进行 CH1 12 V / 0.5 A 的空载输出测量。

S1 启动后是连续输出，松开 S1 不会停止；S2 停止。S3 切换方向并停止，需重新按 S1 启动。
本版本没有自动运行时限或独立硬件急停，仅用于当前电机断开的诊断。
断开 FPGA USB 电源后，SRAM 程序会丢失，需要重新下载。

## 对比记录

原 20 kHz / 10% 的用户测量：B+ 对 B− 12 V，VCC 对 GND 5 V，R_EN / L_EN 均 5 V；
RPWM 对 GND 的 DCV 0.5 V、ACV 1.5 V、频率 20 kHz；
空载 M+ 对 B− 的 DCV 0.3 V、ACV 1.25 V、频率 20 kHz，M− 对 B− 的 DCV 0 V。

理想 0～12 V、10% 占空比方波的直流平均值为 1.2 V，去除直流后的交流有效值为 3.6 V。
这两个值仅作为对照，实际还取决于驱动时序、波形和仪表带宽，不能作为单项损坏判据。

如果降低频率后输出明显恢复，支持短脉冲响应受限的假设；若未恢复，仍需进一步定位，不能直接判定驱动损坏。
