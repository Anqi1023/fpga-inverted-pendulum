# 电机保护模块

## 本次内容

`rtl/protection.v` 是可综合的 Verilog 保护逻辑，不是仿真用的替身。
`rtl/motor_protected.v` 将它接入现有 `motor_driver.v → pwm_gen.v → ibt2_adapter.v` 链路。
原有三个电机模块保持原样；既有点动程序和位流不变。
集成模块默认 27 MHz 时钟、1 kHz PWM、1 秒停止等待，保留 30% 占空比上限。
本次不加入未经测试的启动补偿，也不改变 `control_u` 接口；最终控制接口集成另行完成。

## 行为

- 上电或复位后锁定，四路驱动输出为 0。
- `fault=1`、`estop=1` 或 `permit_in=0` 立即撤销逻辑许可，无需等待 PWM 周期结束。
- 集成模块将占空比超过 30% 视为故障，关断并锁存。
- 故障、急停请求在下一有效时钟沿锁存；撤销请求后仍保持锁定。
- 只有故障和急停均解除、外部许可恢复、显式 STOP（`command=00`）且 `arm=0` 时，新的 `clear_fault` 上升沿才可清除。
- 清除仅恢复许可，不启动电机。停止等待结束后，还要在 STOP 下给新的 `arm` 上升沿，再发正转/反转命令。
- 触发保护和清除同时发生时，保护优先。
- 上电时一直按住清除键，或在故障期间提前按住清除键，均不会自动解锁。须松开后重新按。
- `fault_latched` 和 `estop_latched` 分别记录两种原因，支持先后发生并累计；复位或有效清除后归零。仅外部许可丢失时两种原因可以都为 0，但 `locked=1`。
- 普通 STOP 仍按原协议工作，不被记录为故障。

## protection.v 接口

所有请求端口都属于同一个 `clk` 时钟域，高有效。`rst_n` 低有效。

| 接口 | 含义 |
|---|---|
| permit_in | 上级运行许可；0 会锁定 |
| fault | 已判定的故障请求 |
| estop | 已处理的急停请求 |
| stop_request | 确认处于允许清除的停止请求状态；由集成层生成 |
| clear_fault | 手动清除请求，要求新的上升沿 |
| permit | 送给电机模块的运行许可 |
| locked | 当前是否锁定，包含启动后的初始锁定 |
| fault_latched / estop_latched | 锁存的原因标志 |
| clear_accepted | 有效清除的一拍确认脉冲 |

`motor_protected.v` 从 `command==00 && arm==0` 产生 `stop_request`。
00 和 11 都能使原电机模块停止，但清除故障特意只接受显式 00。
复位至少覆盖一个上升沿，并同步释放；可沿用现有 `reset_guard`。
`fault`、`estop`、`permit_in` 的关断条件至少覆盖一个上升沿，才能保证锁存。
输入发生变化到许可、PWM、EN 撤销是组合逻辑传播延迟，RTL 不等待时钟或 PWM 周期；真实纳秒延迟须在完成板级布局布线后测量。

## 边界

裸按键和外部异步故障线不能直接当作这些同步接口；板级顶层需处理同步/脉冲捕获及有效电平，急停路径不应使用普通 10 ms 按键防抖延时。
本模块不测量电流、温度或摆角，需要其他模块产生 `fault`。
逻辑急停不等于独立硬件断电；时钟故障、配置期间及 FPGA 失电时的硬件禁止尚未由此解决。
这里的“停止”表示 PWM 和 EN 归零，不保证旋转机构立即机械静止。

## 验证与复现

在本工程目录执行：

```text
.\run_protection.ps1
gw_sh build_protection_synth.tcl
```

PowerShell 仿真脚本分别启动保护单元、1 kHz 集成链路、原电机/适配器回归，并逐项检查 PASS 和退出状态。
若 vsim 未在 PATH 中，可给脚本传入 `-Simulator` 指定 vsim.exe 完整路径。三个日志分别为 tb_protection.log、tb_motor_protected.log、tb_motor.log。
单独运行 run_protection.do 默认只测试集成链路，不等于完整回归通过。
应看到 `PROTECTION_UNIT_PASS`、`MOTOR_PROTECTED_INTEGRATION_PASS`、`HENGXIN_MOTOR_OFFLINE_PASS` 和 `HENGXIN_IBT2_ADAPTER_PASS`，并核对无错误。
集成仿真用实际 27000 拍 PWM 周期，检查两方向 10%、20%、30%；只将停止等待缩短为 20 拍。
检查在 PWM 高电平期间触发故障/急停时四个驱动引脚清零，以及故障消失、清除、复位和按住启动时不自动重启。

本工程仅综合，不运行布局布线，也不生成供实物下载的 `.fs`：保护按键和故障源尚未映射到板级接口。
现有点动 `.fs` 不会因为增加这个文件就自动获得保护功能。实板验收需要之后生成专用板级程序。

- ModelSim 2020.1：三个独立仿真均成功，编译及仿真报告均为 0 错误、0 警告；所有要求的 PASS 标记齐全。

- 集成链路：1 kHz 下两方向 10%、20%、30% 的输出脉宽；在实际高电平脉冲中注入 fault/estop，四路输出在下一时钟沿之前均为 0；故障解除、非法清除、复位、许可恢复及占空比恢复不自动启动；正常停止和新启动协议仍通过。
