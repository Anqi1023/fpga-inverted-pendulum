# A 组彻底完成路线与状态清单（旋转倒立摆）

更新日期：2026-09-17。目标分支：`feature/sensor`。

> 纠错说明：本项目是旋转倒立摆，不是直线小车倒立摆。此前关于小车位移、
> mm/rev、position 单位 mm 和 position_vel 单位 mm/s 的内容均作废。

固定路线：

`确认旋转机构参数 -> 接线/管脚 -> 完善并综合代码 -> 实机标定 -> 验证并交付 C 组`

## 1. 系统结构

```text
WDD35D4 模拟角位移传感器
        -> ADS1115 ADC -> I2C
        -> angle / angle_vel（摆杆）

电机输出轴霍尔 A/B 编码器
        -> 电平适配 -> 四倍频正交解码
        -> position / position_vel（旋转臂）
```

`position` 表示旋转臂角位置，不表示直线位移。最终可与 C 组协商改名为
`arm_angle`，但统一接口前保持题目要求的 `position` 名称。

## 3. FPGA 接口暂定分配

| 信号 | FPGA 管脚 | 用途 |
|---|---|---|
| clk | H11 | 27 MHz 板载时钟 |
| rst_n | T10 | 系统复位 |
| position_enc_a | T6 | 旋转臂编码器 A 相，经电平适配 |
| position_enc_b | P6 | 旋转臂编码器 B 相，经电平适配 |
| ads_scl | T8 | ADS1115 I2C SCL |
| ads_sda | P8 | ADS1115 I2C SDA，开漏双向 |

T7、R6/R8 不再分配给“摆杆 A/B 相”，因为 WDD35D4 是模拟传感器。
用户 PDF 中 PMOD0 标为 R6，实物照片/此前记录显示 R8；当前方案避开该争议脚。

## 4. 接线与电气安全

### WDD35D4 与 ADS1115

| WDD35D4 | ADS1115/电源 |
|---|---|
| 绿色标记输出端 | AIN0 |
| 中间端 | 3.3 V |
| 另一端 | GND |

ADS1115 暂定 `ADDR -> GND`，7-bit 地址 `0x48`；`A/R` 暂不接。
模块供电、SDA/SCL 上拉电压必须实测确认后才能接 FPGA。

### 霍尔编码器

编码器资料端子：1 电机线负、2 编码器电源、3 A 相、4 B 相、5 编码器地、6 电机线正。
电机线 1/6 归 B 组；A 组使用 2/3/4/5。

编码器 5 V A/B 不能直接接 FPGA。CJMCU-245 的 LJ245A 已确认是 SN74LVC4245A，
编码器降压接法为：`VCA=5 V`、`VCB=3.3 V`、`DIR=VCA`、`OE=GND`，编码器
A/B 分别进入 A1/A2，FPGA T6/P6 分别接 B1/B2，所有 GND 共地。上电后先只接模块，
测得 B1/B2 高电平约 3.3 V 后再连接 FPGA。

## 5. RTL 当前状态与必须修改项

已有且可复用：

- `quadrature_decoder.v`：A/B 四倍频、正反计数、两级同步、非法跳变检测。
- `velocity_estimator.v`：固定采样窗口差分框架。
- 编码器和速度 Testbench 已通过 Icarus；用户反馈 ModelSim GUI 通过。

当前错误：`sensor_state.v` 仍将摆杆当作第二路 A/B 编码器。真实硬件是
`WDD35D4 -> ADS1115 -> I2C`，因此必须重构。现有 angle/position 仍是原始 count，
没有物理角度单位、I2C 故障检测、滤波或实机标定。

后续由 Codex 实现：

1. ADS1115 I2C 主机：配置 AIN0、读取转换寄存器、ACK/NACK、超时。
2. ADC 整数滤波，窗口参数化。
3. `angle`：ADC 零点和比例标定后的摆杆角度。
4. `angle_vel`：固定周期摆杆角速度。
5. 编码器四倍频，换算常数采用 1040 count/rev，并以整圈实测验收。
6. `position`：旋转臂角位置，不进行毫米换算。
7. `position_vel`：旋转臂角速度。
8. `sensor_valid`：ADC 初始化、ACK/超时/范围、编码器异常和标定状态。
9. 新 Testbench：模拟 ADS1115 I2C、正常运动、NACK、超时、越界和静止。
10. Gowin 顶层、`.cst`、`.sdc`、`.gprj`，并运行综合。

## 6. 实机标定

摆杆：

1. 摆杆竖直向上，记录 ADC 均值，定义 `angle = 0`。
2. 在至少两个已知角度记录 ADC 值，计算 ADC-count/rad 或 ADC-count/degree。
3. 确定摆杆正方向。
4. 记录静止噪声，确定滤波窗口和速度死区。

旋转臂：

1. 将旋转臂放在规定机械零位，定义 `position = 0`。
2. 旋转臂准确转一圈，核对是否为 1040 count；若不符，停止使用商品标称值并记录实测值。
3. 确定旋转臂正方向。
4. 核对一圈输出是否等于约 360° 或 `2π rad` 的目标定点值。

旋转倒立摆不需要测 mm/rev。商品页把 260 脉冲定义在减速器输出轴，商品结构为
长轴电机带旋转臂；仍用整圈计数检查装配中是否存在额外传动。

## 7. 与 C 组必须统一

- 四个状态量的单位、位宽和定点格式。
- `position` 是否做 0-360° 回绕或保持累计角度。
- 更新周期：候选 10 ms / 100 Hz，需 C 组确认。
- 两个角度的零点和正方向。
- `sensor_valid` 的有效时序、故障条件和恢复方式。

## 8. 完成标准

- 转动摆杆：`angle` 符号和数值与已知角度一致。
- 快慢转摆杆：`angle_vel` 方向正确，快转绝对值更大。
- 转动旋转臂：`position` 按角度正确变化，一圈比例正确。
- 快慢转旋转臂：`position_vel` 方向正确，快转绝对值更大。
- 全部静止：两个速度接近 0。
- 正常采集：`sensor_valid=1`；I2C NACK、超时或明显越界时变为 0。
- Gowin 综合通过，C 组可直接使用五个输出。
