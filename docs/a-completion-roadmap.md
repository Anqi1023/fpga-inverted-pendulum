# A 组完成状态（旋转倒立摆）

更新：2026-09-17。直线倒立摆、mm/rev、小车 position 等旧结论全部作废。

## 已完成并写入仓库

1. 从厂家旋转倒立摆 STM32 原始代码确认：霍尔编码器四倍频按 **1040 count/rev**；
   状态更新周期 **20 ms（50 Hz）**。
2. 确认原机 WDD35D4 使用 3.3 V、STM32 12 位 ADC 通道 3；厂家换算为
   `angle=(3100-adc12)*0.0879°` 并在原始码低段处理 360° 回绕，随后取反得到 alpha。
3. 完成 ADS1115 I2C 驱动：地址 0x48、AIN0 单端、±4.096 V、连续 860 SPS；每
   1.25 ms 读取一次，16 点平均后每 20 ms 更新状态。
4. 完成编码器四倍频、角度和角速度换算，四个状态统一输出 signed Q16.16：
   `theta/theta_dot/alpha/alpha_dot`，单位为 rad 和 rad/s。
5. 完成 `sensor_valid`、I2C NACK 故障、非法编码器跳变锁存，以及 115200 UART 数据包。
6. 仿真全部通过；Gowin 综合、布局布线、时序分析和比特流生成通过。
7. 固定 A/B/C 资源：B 使用 PMOD0；A 使用 PMOD1 的 M14/M15/J14/J16。

## 仍必须由实物操作完成

1. **ADS 电气测量**：模块只接 3.3 V/GND，确认芯片 VDD、SDA/SCL 空闲电压均约
   3.3 V，断电测 SDA/SCL 到 VDD 的上拉阻值。任何一根总线高于 3.6 V 都不能接 FPGA。
2. **编码器电平测量**：编码器用 5 V；A/B 各经 12 kΩ 串联、22 kΩ 对地的分压后，
   高电平应在约 3.0-3.3 V。测量合格后才接 M14/M15。现有 CJMCU-245 已分配给 B 组
   电机控制，且器件只有一个公共 DIR，不用于这两路编码器。
3. **下载与方向检查**：下载 `fpga/sensor/output/sensor_acquisition.fs`，转动旋转臂，
   核对 theta 正负方向和准确一圈是否为约 2π；若相反，交换编码器 A/B。
4. **摆杆复标**：竖直向上记录 alpha，核对零点；在已知角度记录至少两组数据，确定
   实物偏置和比例。当前常数来自厂家原机 12 位 ADC，能工作但不能替代本机标定。
5. **最终验收**：静止时两个速度接近 0；快慢、正反转均正确；拔开 ADS 或制造 NACK
   后 `sensor_valid=0`。故障锁存后按复位键恢复。
6. **与 C 组冻结**：确认 Q16.16、rad/rad/s、50 Hz、正方向、零点和累计 theta 的约定。

硬件测量与实机动作不能由仓库自动完成；除此之外，A 的 RTL、约束、仿真、构建和串口
查看工具已经齐全。
