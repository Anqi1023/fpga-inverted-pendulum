# B 最新引脚与 C 交接：BANK2 三引脚版

更新：2026-10-08。此分配取代 B 旧 T6/P6/T8/T9；R12/R13/T12/T13 的审查方案不采用。

| B 顶层端口 | FPGA 球位 | 电平转换器输入 | 转换器输出 → IBT-2 |
|---|---|---|---|
| rpwm | T11 | B1 | A1 → RPWM |
| lpwm | P11 | B2 | A2 → LPWM |
| ibt_en | T12 | 同时接 B3、B4 | A3 → R_EN；A4 → L_EN |

三脚均 BANK2 / LVCMOS33 / 3.3 V。一个 T12 输出分到两个输入；A3/A4 保持独立，不能短接。
RTL 内部保留 r_en/l_en，物理 ibt_en = r_en && l_en。C 的 motor_enable 是协议输入，不能拿它替代物理 ibt_en。
T11/P11/T12 对应 Dock 3713 的 DVP_D1/DVP_D2/DVP_D0，使用本方案时摄像头及占这些脚的外设不连接。
C 整合时须确认自己的其他逻辑没有占用这三脚；本次没有检查或修改 A/C 的最新分支。

## 两个不同用途的入口

- **B 独立点动**：[完整高云工程](../fpga/motor/experiments/motor_control_v1_bank2_3pin/README.md)。模拟 C，1 kHz、10%、200 ms；上电锁定，第一次 S1 清锁，再次 S1 点动。
- **C 正式集成**：[integration](../fpga/motor/experiments/motor_control_v1_bank2_3pin/integration/README.md)。实例化 motor_control_u_chain_3pin，包含 control_u_adapter 和原 motor_protected 执行链，没有模拟命令或 200 ms 点动限制。
- [联合 CST 三脚片段](../fpga/motor/experiments/motor_control_v1_bank2_3pin/integration/B_motor_bank2_3pin.cst)：合入唯一联合 CST，移除旧 B 的四输出约束，不能把两个输出端口同时约束到 T12。

原五个驱动模块和 control_u_adapter 未改；只新增三脚包装模块并调整板级顶层、约束及测试。
C 接口仍为 signed[15:0] control_u（±300、单位 0.1%）、20 ms 单拍 control_valid、motor_enable；100 ms 看门狗、整数百分比截断及保护优先级保留。
1 秒停止/换向等待仍保留；尚未验收倒立平衡闭环。
