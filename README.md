# 双模式工程：精简遥测版

本版以Gowin已测21439的资源修复1为基线，删除非必需遥测逻辑；不叠加资源修复2/3。

## 保留

- 模式0：姿态PID与并联巡航反馈，平衡优先、扰动恢复。
- 模式1：定位协调、位置外环PI/姿态内环PD、多圈目标、轨迹及近点减速。
- 停机切换、独立模式参数、串口读写及配置导入导出。
- 起摆、捕获、PWM、执行链、停机、急停及保护。
- 网页基本曲线：摆杆角度、横臂累计角度、速度、电机输出、巡航目标/参考、定位目标/轨迹、外环积分角度。

## 删除

生产RTL不再包含完整遥测格式器，改为25字段的sensor_packet_lite。删除PA/PD/PT/PV/PI分项、原始ADC内部数据、重复原测速、旧定点调试快照、低层横臂请求诊断及测量年龄字段。缺失数值由网页显示为不可用，CSV对应列为空。移除对应的曲线按钮，保留控制速度与混合测速。

这些删除只作用于观测数据；积分控制及保护没有关闭。事件记录器在基线中已经停用，本版不把它计为新增节省。

旧完整报文模块只保存在sim/sensor_packet_full_reference.v中供兼容性仿真使用，不在Gowin工程引用列表内。控制、采集、参数、执行链RTL与资源修复1逐字节一致；top仅替换只读遥测实例。

## 编译及使用

解压到新文件夹，打开gowin_project/inverted_pendulum.gprj。网页入口pc/start_web_panel.bat。停止→选择模式→应用并回读→启动。

## 验证边界

顶层编译、双模式原控制器逐拍对照、积分、巡航恢复、轨迹、停机切换、参数/串口、保护与网页兼容测试已通过。新增真实精简报文模块仿真验证了两模式、负数/INT32_MIN、帧内快照冻结、UART握手和Python解析。

Yosys局部LUT4映射：遥测模块2010→856 LUT、1007→706寄存器。该结果不能替代Gowin整机综合。尚未验证本版Gowin资源、布局布线、时序及实板表现，不能保证低于20736。
